# RC3 캐릭터 리마스터 PRD

## 목표

RC2의 비행과 미션 계약을 보존하면서 주홍 드래곤의 얼굴, 해부학, 실루엣과 반응 표현을 게임 카메라에서 확실히 개선한다.

## 사용자 결과

- 준비 화면에서 드래곤의 얼굴과 성격을 즉시 인식한다.
- 레이스에서는 날개, 어깨, 몸통, 꼬리가 살아 있는 비행 생물처럼 반응한다.
- 작은 모바일 화면에서도 다음 관문과 바람실을 잃지 않는다.

## 범위

- Dragon v3 Blender 자동화/GLB
- 선택 턱·눈 피벗과 fallback
- 호흡, 눈 깜빡임, 상승, 부스트, 충돌 표현
- 준비 화면 영웅 구도
- 5뷰포트 자동 QA

## 비범위

새 드래곤, 새 코스, 전투, NPC, 퀘스트, 꾸미기, 백엔드, 새 의존성.

## 완료 기준

제품/성능 불변 조건과 M10~M13 완료 조건을 모두 통과하고 사람 결과를 주장하지 않은 RC3 인계 문서를 만든다.
