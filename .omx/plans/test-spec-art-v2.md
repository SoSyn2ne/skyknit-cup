# Art V2 test specification

1. Inspect builder exports and reload both actual GLBs. Assert finite positions/normals, nonzero triangle count <=60000, primitives <=24, expected dragon and hub semantic nodes. Report materials and raw/gzip bytes; do not equate compression to production readiness.
2. Browser regression tests written before preview implementation. Start current Vite on localhost:4176. Use tests/e2e/art-preview.spec.ts and existing Playwright config. Test scene/dragon/hub, new/current, pause/resume, wireframe, camera reset, failure/retry, and rapid selection with async loads (stale loads must not replace current choice). Verify reduced-motion default and unchanged localStorage.
3. Five sizes: 1440x900, 1280x720, 844x390, 390x844, 320x568. Canvas varied pixels and changed pixels over time; paused frames stable after settling; viewport framing and nonoverlapping 44px controls; no horizontal overflow, console errors or unhandled rejections. Capture screenshots of real GLBs. Desktop/mobile emulation is not physical-device validation.
4. Measure cold-load GLB transferred bytes and a 30-second preview frame-time/FPS sample, DPR, draw calls and triangles. Report hardware/software renderer and do not claim game performance passed. Dev-only tests explicitly skip M6_PRODUCTION mode. Fresh npm test, npm run typecheck, npm run lint, npm run build. Check production build contains no new Art V2 GLB, and old game entry untouched. Tests/build failures from unrelated existing work must be reported, not silently bypassed.
5. Persist visual verdict score/reasons/next actions after inspection and before edits. Reference is assets/source/art-v2/reference/skyknit-rebuild-target.png; actual screenshots/renders must be distinguished. Do not award reference equivalence based on controls or triangle budgets.
6. Independent architect sign-off, scoped cleanup review and post-cleanup rerun. Check git status and list changed files plus production/real-device/human gaps.
