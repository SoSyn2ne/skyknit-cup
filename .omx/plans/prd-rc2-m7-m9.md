# 하늘매듭배 RC2 PRD — M7~M9

> 상태: **승인됨 / 실행 가능**
>
> 기준일: 2026-07-11
>
> 사용자 목표: 3D 품질을 올리고 기존 코스에 반복 도전 가능한 미션을 추가한 뒤 RC2 자동 QA까지 완료한다.

## 1. RC2 한 문장 목표

주홍 드래곤과 하늘 군도의 시각 품질을 한 단계 올리고, 같은 1랩 코스를 여섯 가지 명확한 로컬 챌린지로 다시 즐길 수 있게 한다.

## 2. 범위

### 포함

- M7: 드래곤 v2, 군도/유적/깃발/룬/구름/관문 시각 리마스터
- M8: 같은 코스를 사용하는 로컬 싱글 플레이 미션 6종
- M9: 5개 뷰포트, 픽셀, 오류, 네트워크, 성능, 전송량, 프로덕션 제거 자동 QA와 인계

### 제외

- 새 코스, 복수 드래곤, 자유 탐험, 스토리 캠페인, NPC, 대화, 전투
- 계정, 백엔드, 서버 순위표, 온라인 동기화
- 후처리, 새 런타임 라이브러리, 출처 불명 외부 에셋
- 사람 플레이테스트 결과의 추정 또는 대체

## 3. 제품 불변 조건

- 주홍 드래곤, 금빛 다음 관문, 두 가닥 바람실을 모든 시각 수정의 우선순위로 둔다.
- 기존 자동 전진 비행, 관문 순서, 리스폰 진행 보존, 타이머 지속 규칙을 바꾸지 않는다.
- 키보드와 터치가 미션 선택부터 결과 확인/재시도까지 모두 완결된다.
- full-bleed Three.js 장면과 기존 접근성/reduced-motion/복구 계약을 보존한다.

## 4. M7 요구사항

### 드래곤 v2

- 총 15,000~25,000 triangles.
- 런타임 이름 `WingRig_L`, `WingRig_R`, `HeadRig`, `TailRig_1..5` 보존.
- 머리/눈/뿔/목/몸통/다리/발톱/날개막/꼬리 비율과 faceting 개선.
- 날갯짓, 어깨 선행 뱅크, 몸통/꼬리 지연, 상승/부스트 자세 보존.
- vertex color 또는 1024px 텍스처 1장.
- 피벗 안의 정적 장식은 병합하고, 드래곤 렌더 메시 목표를 16개 이하로 둔다.

### 세계

- 섬은 높이/폭/하부 암반의 실루엣 변화를 늘린다.
- 유적, 작은 깃발, 관문 주변 룬을 제한된 반복 세트와 인스턴싱으로 추가한다.
- 구름은 원경/중경 레이어를 분리하되 저품질 모드에서 밀도를 줄인다.
- 관문은 금빛 활성 상태와 청록 룬을 더 분명히 하되 화면 공간 크기와 방향 표시 규칙을 유지한다.

### 예산

- high 장면 draw calls <=120.
- desktop/high 30초 bucket median >=55fps, minimum >=50fps.
- mobile/low 30초 bucket median >=30fps.
- 보수적 전체 gzip <10MiB.

## 5. M8 미션 계약

### 공통 등급

등급은 `failed | bronze | silver | gold`다. 성공은 bronze 이상이다. 더 높은 등급만 로컬 최고 등급을 갱신한다.

| ID | 이름 | Bronze | Silver | Gold |
| --- | --- | --- | --- | --- |
| `first-skyknot` | 첫 하늘매듭 | 완주 | 210초 이내 완주 | 180초 이내 완주 |
| `time-trial` | 질풍 시간전 | 180초 이내 | 165초 이내 | 150초 이내 |
| `clean-flight` | 구름 한 점 없이 | 충돌 0회 완주 | 충돌 0회 + 210초 이내 | 충돌 0회 + 180초 이내 |
| `no-respawn` | 끊기지 않는 매듭 | 리스폰 0회 완주 | 리스폰 0회 + 210초 이내 | 리스폰 0회 + 180초 이내 |
| `boost-mastery` | 돌풍 조율사 | 부스트 활성화 3회 이상 완주 | 5회 이상 | 7회 이상 |
| `golden-knot` | 황금 하늘매듭 | 210초 이내, 충돌 1 이하, 리스폰 1 이하, 부스트 3회 이상 | 195초 이내, 충돌 0, 리스폰 1 이하, 부스트 4회 이상 | 180초 이내, 충돌 0, 리스폰 0, 부스트 5회 이상 |

시간 값은 현재 제품 목표 2~4분을 기준으로 한 RC2 초기 튜닝값이다. 규칙 상수로 중앙화하고 M9 자동 성능/기능 게이트와 사람 플레이테스트를 분리한다.

### 시도 통계

각 시도는 다음 값을 가진다.

- 선택 미션 ID
- 시작 여부와 완료 여부
- 경과 레이스 시간(ms)
- 현재/최종 체크포인트 인덱스
- 충돌 횟수
- 수동+자동 리스폰 횟수
- 실제 부스트 시작 횟수(키 반복이나 눌린 채 유지 제외)

### 생명주기

- 준비: 미션 선택 가능, 시도 통계는 아직 증가하지 않음.
- 카운트다운: 선택 고정, 통계 증가 없음.
- 레이스: 레이스 이벤트로만 통계를 갱신.
- 일시정지: 시간과 모든 통계 정지.
- 재시도: 선택 미션은 유지하고 통계 0의 새 시도 생성.
- 컨텍스트 복구: 선택 미션, 진행 중 시도 통계, 레이스 체크포인트/시간을 보존.
- 완주: 한 번만 평가하고 최고 등급을 저장.

### 저장 v3

```ts
type PersistedSettingsV3 = {
  version: 3;
  bestTimeMs: number | null;
  muted: boolean;
  quality: 'auto' | 'high' | 'low';
  missionGrades: Partial<Record<MissionId, MissionGrade>>;
};
```

- v2의 최고 기록/음소거/품질을 그대로 옮기고 `missionGrades`는 빈 객체로 시작한다.
- 알 수 없는 미션/등급, 비정상 숫자, 손상 JSON은 버리되 게임은 기본값으로 계속 시작한다.

## 6. UI 계약

- 준비 화면: 6개 미션을 이름/한 줄 목표/최고 등급과 함께 선택. 현재 입력 장치의 시작 안내 유지.
- 비행 HUD: 선택 미션 이름, 짧은 목표, 현재 통계 한 줄만 추가. 관문, 타이머, 터치 조작을 가리지 않음.
- 결과: 성공/실패, 이번 등급, 로컬 최고 등급, 조건별 결과, 같은 미션 재시도.
- 모든 미션 선택/재시도 컨트롤은 키보드 포커스 가능, accessible name 보유, touch target 44x44 CSS px 이상.

## 7. M9 완료 정의

- 필수 게이트: `test`, `test:e2e`, `test:performance`, `test:production`, `typecheck`, `lint`, `build`, `npm audit --audit-level=high`.
- 5개 뷰포트에서 선택/진행/성공/실패/재시도 증거.
- canvas nonblank + 시간 변화, console/page/unhandled/network 오류 0.
- M6 대비 triangles/draw calls/raw+gzip 전송량/30초 성능 표.
- 프로덕션 QA/실패 훅 문자열 0.
- 최종 상태: **RC2 / 자동 검증 완료 / 3D·미션 플레이테스트 대기**.

## 9. 결정 기록

- 결정: “미션”은 같은 코스를 재사용하는 챌린지 규칙이다.
- 이유: 현재 제품의 1코스/1드래곤/짧은 레이스 정체성을 유지하면서 반복 플레이 목표를 만든다.
- 거절: 새 맵/스토리 캠페인 — RC2 범위와 24시간 자동 실행 예산을 넘고 시각·규칙 QA를 분산한다.
- 지시: 임계값 튜닝은 중앙 상수에서만 하고 미션별 조건을 UI 코드에 복제하지 않는다.
