## 결론

서로 독립적으로 열려 있던 기존 여섯 미션을 하나의 영구 진행 경로로 연결했다. 새 저장은 `첫 하늘매듭`만 열리고, 현재 미션에서 브론즈 이상을 얻으면 다음 미션이 열린다. 뒤 미션은 완주, 돌풍 사용, 무리스폰, 제한 시간, 무충돌 조건을 순서대로 누적하며 최종 `황금 매듭`은 강화된 종합 도전이 된다.

준비 화면과 `Esc` 일시정지는 동일한 미션 선택기를 사용한다. 잠긴 미션도 여섯 개 모두 보이지만 선택할 수 없고, 바로 앞 미션의 브론즈가 필요하다는 이유를 표시한다. 성공 결과의 `다음 미션`은 새로 열린 도전을 선택한 준비 상태로 이동하며 자동 출발하지 않는다. 마지막 미션 성공 시에는 전체 완료를 알린다.

새 저장 필드나 미션 ID를 만들지 않았다. 해금은 기존 v8 최고 등급과 정규화된 미션 기록판에서 파생하므로 기존 등급, Top 10과 고스트가 그대로 남는다. 후반 미션 기록만 있는 오래된 저장은 해당 단계까지의 접근권과 바로 다음 단계를 복원하지만 가짜 등급, 순위 또는 고스트를 만들지 않는다. 비행 물리, 코스, 관문, 카메라, 충돌과 리스폰 구현은 변경하지 않았다.

## 진행 순서와 브론즈 기준

| 단계 | 기존 미션 ID | 브론즈 성공 기준 |
| ---: | --- | --- |
| 1 | `first-skyknot` | 코스 완주 |
| 2 | `boost-mastery` | 완주 + 돌풍 3회 이상 |
| 3 | `no-respawn` | 앞 조건 + 리스폰 0회 |
| 4 | `time-trial` | 앞 조건 + 210초 이내 |
| 5 | `clean-flight` | 앞 조건 + 충돌 0회 |
| 6 | `golden-knot` | 180초 이내 + 충돌 0회 + 리스폰 0회 + 돌풍 5회 이상 |

실버와 골드는 같은 누적 조건을 유지하면서 시간과 돌풍 기준만 더 엄격해진다. 실패 결과는 처음 걸린 한 항목만 숨기지 않고 충족하지 못한 브론즈 조건을 모두 보여 준다.

## 저장 호환과 단순화

- 저장 키와 스키마 버전은 기존 `skyknit-cup:settings` v8을 유지한다.
- `missionGrades`와 정규화된 미션 기록판의 등급만으로 해금을 파생한다.
- 최고 등급은 내려가지 않으며 브론즈·실버·골드 모두 다음 단계 해금으로 인정한다.
- 손상되거나 알 수 없는 등급과 미션 ID는 기존 정규화 규칙대로 무시한다.
- 잠금 선택은 DOM의 `disabled`뿐 아니라 레이스 상태 전이에서도 다시 차단한다.
- 준비와 일시정지에 별도 목록을 만들지 않고 한 선택기와 한 잠금 사유 포맷을 공유한다.

## 남은 사람 판정

- 실제 새 저장에서 여섯 단계의 난이도 상승이 학습 곡선으로 느껴지는지 확인한다.
- 브론즈 해금 직후 `다음 미션`이 자연스럽게 다음 시도를 유도하는지 확인한다.
- 실제 Android와 iPhone에서 `Esc` 대응 일시정지 선택기, 잠금 문구와 터치 크기를 확인한다.
- 기존 v8 플레이 저장을 백업한 뒤 등급, Top 10, 고스트와 해금 상태가 함께 유지되는지 확인한다.
- 최종 종합 도전의 180초·5돌풍 기준이 지나치게 쉽거나 막히지 않는지 사람 플레이로 조정 판단한다.
