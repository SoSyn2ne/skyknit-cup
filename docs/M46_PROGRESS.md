- 사용자가 현재 진행분의 커밋·푸시를 요청했다. 이번 체크포인트만 기존 `codex/m41-guardian-motion` 브랜치로 공유하며, main 병합·배포나 M46 완료 선언은 하지 않는다.
- 현재 코드에는 `staticPrelitMaterial.ts`의 정점 조명 실험을 축제섬과 둥지 정적 구조에 연결했다. 원본 GLB·수호수·의뢰 인물·비행 규칙은 보존한다. 정적 구조의 diffuse/emission을 정점에서 계산하며 PBR specular와 received shadow는 동일하지 않다.

- `.claude`, `.omx`, 빌드 산출물, 임시 스크린샷·진단 로그는 이 공유 커밋에서 제외한다.

## 목표 완료를 위해 남은 작업

1. **성능 실패 원인부터 수정.** 최신 desktop/high의 활성 거점27fps·복구 후25fps는 지속적인 실패다. 새 내용 추가를 잠시 멈춘 상태다. CDP10초에서 task0.37s/JS0.19s/layout0.033s이고, 동일카메라720×450 진단에서21→54fps라 GPU 화면 채움 비용이 지배적이다. 단면/재질/그림자/그리기 순서 A/B는 별도 진단 JSON에 기록했다. 그림자 동결·재질 단순화·해상도 축소는 제품에 적용하지 않았다. Terrain/Nest/SecretPath의 뒷면 제외만 PBR·색을 유지하며 반영했고14개 월드 테스트와 수정된 지형 검사가 통과했다. 남은 비용은 기존 정적 배경+신규 표면을 함께 분리해 확인해야 한다. `createOpenWorld.ts`에는 용암 지역 전용Lambert 변환 선례가 있으나 다른 지역에 무조건 확대 적용하지 말고, 별도 측정·시각 검증이 필요하다. 목표·품질을 낮춰 통과시키거나 M45 수치를 재사용하지 않는다.
2. **10~15분 첫 챕터 콘텐츠 보강.** 현재 알려진 정답 자동 경로253/204초로 첫 플레이 분량 근거가 부족하다. 의뢰3은 정확한 목표 비콘에 가서 감지 버튼을 누르는 구조라 실제 탐색이 약하다. 지역 단서→감지→숨은 지점 직접 발견의 공간 행동, 방문한 단서의 영구 흔적을 보강하는 것이 다음 콘텐츠 작업이다. 강제 대기·반복 채집·빈 이동으로 시간을 채우지 않는다.
3. 신규 기본 진입과 v12 변경에 관련된 기존 E2E 회귀를 실행한다. 기존 sky-league 마이그레이션 기대값11을12로 고쳤으나 전체 브라우저 회귀는 아직 남았다.
4. 성능 수정 뒤6개 M46 상태와 기존 기록 모드 전체 성능을 재측정한다.
5. 실제 수호수 매듭의 적용/해제 동일 카메라, 5뷰포트 보상 패널·초기 음향/복구 수명주기를 감사한다. production10개와 최종GLB 기본 모험5개는 통과했다.
6. 사람·실기기 검증 미실시를 명시하고 요구사항별 완료 증거를 QA 보고서에 연결한 뒤에만 Goal 완료 처리한다.

이 목표 턴의 판정은 **progress**: 구현과 시각 수정, 새 실입력 증거를 확보했다. 외부 승인이 필요한 차단 상태가 아니다. 커밋·푸시·배포하지 않았다.
