# M46 돌아오는 바람 — 구현·검증 계약

2026-09-08 사용자 Goal 승인. 구현 게이트 열림. 목표는 10~15분 첫 비전투 모험과 실제 화면의 영구 변화다.

## 플레이

기본 URL은 둥지를 배경으로 시작한다. 짧은 `모험 시작/이어하기` 동작으로 탐험하며, `?mode=race`와 기존 비콘은 기존 레이스 준비로 연결한다. 기존 저장의 탐험 위치는 지우지 않는다. 신규 모험 첫 시작에만 둥지로 진입하고 이후 저장 위치·진행을 복원한다.

의뢰 1: 누리와 대화 → 가까운 바람새 구조 → 둥지 귀환. 첫 3분 내 영구 유대·유적 감지와 등불 장식 보상.
의뢰 2: 누리가 안내하는 피난길/능선길 선택 → 선택 항로의 서로 다른 장치 3~4개 작동 → 풍차 심장·깃발 장식 획득. 안전 경로는 낮고 넓게 돌아가며 능선은 짧고 고도 변화가 있다. 버튼 클릭만으로 원격 완료할 수 없다.
의뢰 3: 감지로 숨은 유적을 찾고 햇실 매듭 확보 → 둥지에서 풍차 복구. 재료 소비와 보상은 한 번만 적용. 돌아가는 풍차, 켜진 등불, 펼쳐진 깃발, 드러난 비밀 길과 신규 수호수 매듭 장식 적용을 확인한다.

### 장치와 탐색 보강

항로의 장치는 가까이 가서 조사하면 바람 회로 퍼즐이 열린다. 조각을 회전해 입구와 출구 사이에 끊김 없는 바람길을 만들고 모든 활성 조각에 바람을 공급한 뒤 작동시킨다. 3×3 입문 → 4×4 수로 → 4×4 공명 → 5×5 심장으로 공간 문제를 확장한다. 오답 페널티나 강제 대기 없이 현재 연결된 조각을 시각적으로 알려준다. 조사 중 비행만 정지하고 모험 플레이 시간·퍼즐 진행은 유지한다. 지도/일시정지/경쟁에서는 퍼즐 입력도 차단한다.

퍼즐 초안은 저장되며 기존 완료 의뢰를 다시 잠그지 않는다. 즉시 정답을 아는 자동 입력의 소요 시간과 첫 플레이의 탐색/문제 해결 시간을 구분한다. 의도된 첫 플레이 시간표는 구조 1~2분, 항로 이동·장치 해결 5~7분, 유적 탐색·복구·정원 발견·꾸미기 3~6분이며 실제 측정으로 재검토한다.

복구 후 석판길 끝에 실제 작은 비밀 정원을 만든다. 해당 정원에 도달해 상호작용하면 발견과 유대가 한 번만 저장되고 마지막 목표가 완료된다. 단순한 장식 길을 목적지 완성으로 취급하지 않는다.

현재 목표는 한 개만 강조한다. 각 단계는 다른 이동/공간 상호작용을 요구한다. 10~15분 목표를 맞추기 위해 강제 대기나 반복 채집을 추가하지 않고 실제 여행·선택·발견으로 구성한다. 자동 최단 경로와 사람의 첫 플레이 시간은 구분한다.

## 구조 및 소유권

- `src/game/adventure/adventureState.ts`: 순수 진행, 보상, 정규화, 성장, 경쟁 모드 가드.
- `src/game/adventure/adventureWorld.ts`: 좌표·항로·상호작용 지점·둥지 착륙장 데이터.
- `src/game/persistence/records.ts`: optional adventure 입력을 읽어 canonical v12 저장. 구 데이터·미션·기록·고스트·외형·탐험 위치 보존.
- `src/game/ui/AdventureHud.ts` + 독립 CSS: 도입, 한 줄 의뢰, 항로 선택, 감지, 장식·외형 보상 적용. 접근 가능한 이름과 44px 터치.
- `tools/blender/build_adventure_hub.py`: 별도 원본/GLB. 둥지·풍차·누리·바람새·유적·장식·주변 절벽을 실제 형태로 제작.
- `src/game/world/createAdventureWorld.ts`: 위 GLB 로드, 위치 배치, 복구 전후·바람새·풍차 회전·숨은 길과 목표 표식; dispose/late load 처리.
- `src/game/createRenderer.ts`: 기본 진입·실제 E/터치 상호작용·저장·모드별 시각·경쟁 중 성장 비활성화 통합. 루트 단독 소유.

UI/시각은 순수 상태를 읽고 action callback만 호출한다. reducer는 불변 갱신이며 `return state`로 거부/중복 요청을 표현한다. 입력·시간·위치 유효성을 확인하고, 새 모듈 간 순환 의존성을 만들지 않는다.

## 상태와 보상

의뢰 진행/항로/방문 지점, 구조 대상 동행 여부, 유대 경험, 보상 지급 ID, 보유 의뢰 재료, 감지 해금·발견, 풍차 복구, 장식 배치와 매듭 장착, 모험 활성 플레이 시간을 저장한다.
보상·소비는 공간/단계 조건을 확인한 하나의 순수 전이에서 처리한다. 진행은 되돌아가지 않고 두 번 누르거나 재접속해도 보상을 더 받거나 재료가 음수가 되지 않는다.
기존 외형 잠금은 새로 만들지 않는다. 새 매듭은 수호수 기존 장식과 별개의 보상 부착이며 능력치를 바꾸지 않는다. 감지는 탐험·비경쟁·비일시정지에서만 동작하고 기존 레이스/동전 시도 중에는 숨김과 판정 모두 꺼진다.
