# Milestone 12 RC3 캐릭터 표현 기록

> 상태: **완료 / 5뷰포트 최종 QA 통과**

## 런타임 표현

- 고정 시간 기반의 미세 호흡
- 결정적 짧은 눈 깜빡임
- 부스트 중 눈 좁힘과 턱 열림
- 충돌 중 완전한 찡그림과 짧은 턱/머리 반응
- 기존 어깨 선행 뱅크, 몸통/꼬리 지연과 날갯짓 유지
- pause에서 캐릭터 표현 시간 동결
- 표정 피벗이 없는 fallback 모델 계속 지원

충돌 피드백은 재질의 원래 emissive 색과 강도를 보존했다가 종료 후 정확히 복구한다.

## 카메라

- 준비: 거리 7.5의 후방 3/4 구도, 전신/날개/꼬리와 코스 신호 동시 노출
- 레이스: 목표 거리 8.6, 7 units look-ahead
- 준비에서 출발할 때 카메라를 재초기화해 측면 구도의 잔류와 큰 추적 지연을 제거
- 이동 목표의 속도를 예측하는 feed-forward로 순항 중 실제 카메라 거리를 유지

## 테스트

- `dragonPose.test.ts`: 3개에서 6개로 확장
- 준비 화면은 GLB, 표정 피벗 3개, 드래곤 가시성과 거리 검증
- 레이스는 드래곤, 관문, 바람실과 실제 카메라 거리 검증
- QA boost/hit 흐름은 턱 열림과 눈 찡그림 값을 브라우저에서 검증하고 캡처

## 시각 판정

준비 카메라 6회, 레이스 카메라 2회 반복 후 desktop 기준 95/100을 통과했다. 최신 판정은 `.omx/state/m12/ralph-progress.json`에 있다.

최종 5뷰포트에서 준비 구도, 레이스 구도, boost/hit 표정 시나리오 15개가 통과했다. 세로 모바일 준비 화면은 캐릭터 우선 프레이밍으로 관문이 화면 밖일 수 있지만 레이스 진입 후 드래곤, 두 바람실과 다음 관문이 모두 가시 상태임을 검증한다.
