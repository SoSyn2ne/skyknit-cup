# RC4 소형 오픈월드 플레이테스트 인계

> 자동 상태: **RC4 / 소형 오픈월드 프로토타입 자동 검증 완료**
>
> 사람 상태: **실기기·사람 플레이테스트 대기**

## 테스트 목표

세 지역 탐험이 기존 레이스의 집중도를 해치지 않으면서 드래곤을 조종하고 세계를 발견하는 재미를 주는지 확인한다.

## 권장 기기

- 데스크톱 Chromium 키보드
- 실제 Android 또는 iPhone 가로 화면
- 실제 Android 또는 iPhone 세로 화면

## 확인 순서

1. 준비 화면에서 `하늘 탐험`을 선택하고 축제 중심섬 상공에서 시작한다.
2. W/S/A/D 또는 조이스틱으로 자유 선회하고 C/Ctrl 또는 `감속`을 유지해 완전히 호버한다.
3. 지도를 열어 바람 협곡을 목적지로 지정하고 방향 화살표와 거리가 이해되는지 본다.
4. 바람 협곡과 구름 유적지를 방문해 색, 실루엣, 랜드마크가 서로 구분되는지 본다.
5. 각 착륙장 위에서 상황 버튼으로 착륙하고, 정지 상태와 재이륙 전환이 자연스러운지 본다.
6. 앱을 새로고침해 마지막 위치, 발견 지역, 목적지가 복원되는지 확인한다.
7. 축제 중심섬의 금빛 비콘으로 이동해 `레이스 도전`을 누르고 기존 3초 카운트다운과 선택 미션이 시작되는지 본다.
8. 레이스 완주, 재시도, 일시정지, 리스폰과 Dragon v3 표현이 RC3와 동일하게 동작하는지 본다.

## 기록할 질문

- 세 지역의 방향과 거리를 지도 없이도 어느 정도 기억할 수 있는가?
- 감속에서 정지까지 너무 빠르거나 느리지 않은가?
- 착륙 가능 조건과 상황 버튼이 나타나는 이유를 이해할 수 있는가?
- 지역 간 이동 시간이 지루한가, 아니면 세계 크기를 느끼게 하는가?
- 터치 가로/세로에서 지도, 착륙, 감속, 돌풍 버튼을 잘못 누르는가?
- 탐험에서 레이스로 들어갈 때 목표와 모드 변화가 분명한가?
- 5~10분 탐험 후 멀미, 손가락 피로, 카메라 불편이 있는가?

## 자동 검증으로 대체할 수 없는 위험

- 실제 모바일 GPU 열 throttling과 고DPR 배터리 부담
- notch, rounded corner, 브라우저 UI에 따른 safe-area 차이
- 절차적 랜드마크의 매력과 발견 보상감
- 호버/착륙 조작의 학습성, 장시간 멀미와 피로

문제가 발견되면 기기, 방향, 품질 설정, 현재 지역, 이동/착륙 상태와 가능하면 10초 영상을 함께 남긴다.
