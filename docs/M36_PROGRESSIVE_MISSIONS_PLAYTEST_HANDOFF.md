# Milestone 36 누적 미션 플레이테스트 인계

> 자동 상태: **전체 자동 검증 완료**
>
> 사람 상태: **새 저장·기존 v8 저장 실기기 플레이테스트 대기**
>
> 출시 상태: **완료 아님**

## 목표

미션 잠금이 벌처럼 느껴지지 않고 다음 기술을 익히게 하는 진행 경로로 읽히는지 확인한다. 자동화는 정확한 해금, 누적 조건, 저장 호환과 반응형 UI를 증명했다. 사람은 난이도 감각, 잠금 문구의 이해도와 `다음 미션`의 재도전 유도를 판정한다.

## 세션 A: 새 저장

1. 사이트 저장소가 비어 있는 프로필에서 준비 화면을 연다.
2. `첫 하늘매듭`만 선택 가능하고 나머지 다섯 미션은 보이지만 잠겨 있는지 확인한다.
3. 잠금 문구만 보고 바로 앞 미션 브론즈가 필요하다는 사실을 이해할 수 있는지 기록한다.
4. 첫 미션을 완주하고 결과의 `다음 미션`을 누른다.
5. `돌풍 숙련`이 선택된 준비 화면으로 이동하고 자동 출발하지 않는지 확인한다.
6. 각 미션을 브론즈로 통과하며 돌풍 → 무리스폰 → 제한 시간 → 무충돌 → 종합 조건이 누적된다고 느끼는지 기록한다.
7. 성공·실패마다 결과에 필요한 조건이 충분히 설명되는지 확인한다.
8. 최종 미션 성공 뒤 다음 버튼 대신 전체 완료 안내가 보이는지 확인한다.

## 세션 B: 일시정지와 입력

1. 열린 미션을 시작하고 `Esc` 또는 터치 일시정지를 연다.
2. 준비 화면과 같은 여섯 미션, 같은 순서, 같은 잠금 이유가 보이는지 확인한다.
3. 열린 다른 미션을 선택하면 현재 시도만 취소되고 선택한 미션의 준비 상태로 이동하는지 확인한다.
4. 잠긴 미션은 키보드, 마우스와 터치 어느 방식으로도 선택되지 않아야 한다.
5. 320x568과 844x390에서 미션 선택기, BGM·품질 설정, 계속·리스폰·재시작이 잘리거나 겹치지 않아야 한다.

## 세션 C: 기존 v8 저장

1. 실제 사용 중인 `skyknit-cup:settings`를 백업한다.
2. 기존 미션 등급, 미션 Top 10과 1위 고스트를 기록한다.
3. 게임을 연 뒤 가장 뒤에 기록된 미션까지와 바로 다음 미션이 열리는지 확인한다.
4. 앞 미션에 가짜 등급이나 기록 행이 생기지 않았는지 확인한다.
5. 기존 Top 10, 고스트, 레이스·동전 기록, 탐험 발견과 오디오·품질 설정이 유지되는지 확인한다.
6. 새로 열린 다음 미션을 성공하고 새로고침한 뒤 해금과 기존 데이터가 함께 남는지 확인한다.

## 사람 통과 기준

- 처음 보는 플레이어가 잠금 이유와 다음 목표를 별도 설명 없이 이해한다.
- 각 단계가 바로 앞 단계의 기술을 버리지 않고 한 가지 부담을 더한다고 느낀다.
- 실패 이유가 다음 시도에서 무엇을 바꿔야 하는지 알려 준다.
- 결과의 `다음 미션`이 자연스럽지만 강제 출발로 느껴지지 않는다.
- 데스크톱과 실제 모바일에서 선택기와 세 일시정지 동작을 쉽게 누를 수 있다.
- 기존 v8 데이터가 손실·합성되지 않고 reload 뒤에도 유지된다.
- 비행 감각, 코스, 관문, 충돌과 리스폰이 이전 버전과 같게 느껴진다.
