> 현재 상태: **RC2 / 자동 검증 완료 / 3D·미션 플레이테스트 대기**
>
> 자동 QA: `docs/MILESTONE_9_AUTOMATED_QA_REPORT.md`
>
> 원칙: 아래 결과는 실제 플레이를 관찰한 사람만 기록한다. 에이전트가 추정하거나 대신 채우지 않는다.

## 사람 게이트

최소 3명이 필요하다.

- keyboard 최소 1명, 실제 touch 장치 최소 1명.
- 가능하면 Android Chrome과 iOS Safari 중 하나 이상, 세로/가로 방향 모두 포함.
- 3명 모두 30초 안에 상승/하강, 선회, 부스트를 발견한다.
- 3명 중 2명 이상이 도움 없이 첫 하늘매듭을 완주한다.
- 6개 미션을 세 사람에게 나누어 각 미션을 최소 1회 실제 시도한다.
- blocker 0, 해결되지 않은 major 0이 아니면 출시 완료로 바꾸지 않는다.

## 준비

1. 저장소 루트에서 `npm install`.
2. `npm run dev -- --host 0.0.0.0`.
3. 휴대폰은 같은 네트워크의 LAN 주소로 접속.
4. 첫 플레이 전에 `skyknit-cup:settings`를 지우거나 private session 사용.
5. 화면/음성 기록 전 동의를 받는다.
6. 관찰자는 준비 화면의 문구 외에 조작/미션 조건을 설명하지 않는다.

## 6. 저장·복구 확인

가능하면 한 명에게만 추가 수행한다.

- 미션 Gold/실버/브론즈 중 하나를 얻고 새로고침 후 최고 등급 유지.
- 음소거/화질과 기존 최고 기록도 유지.
- 레이스 중 탭 전환 후 일시정지/통계 정지 이해.
- 개발자가 제공한 context-loss 시나리오에서 미션 진행 보존 확인.

blocker 예:

- 미션 선택, 시작, 비행, 결과, 재시도 중 하나가 불가능
- 다음 관문/바람실을 반복해서 찾을 수 없음
- 터치 컨트롤이나 결과 버튼이 잘리거나 눌리지 않음
- 검은/정지 canvas에서 복구 불가
- 저장 손상으로 게임 진행 불가
- 강한 멀미/불편이 여러 플레이어에게 반복
