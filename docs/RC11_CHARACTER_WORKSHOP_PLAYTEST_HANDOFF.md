# RC11 비행 생명체 작업실 플레이테스트 인계

> 자동 상태: **전체 자동 검증 완료**
>
> 사람 상태: **실기기·선호도 플레이테스트 대기**
>
> 출시 상태: **완료 아님**

## 확인 목표

캐릭터를 바꾸는 재미가 분명한지, 세 종족이 작은 화면에서도 즉시 구분되는지, 외형 선택이 비행과 기록 경쟁을 방해하지 않는지 확인한다.

## 10분 권장 동선

1. 준비 화면에서 `캐릭터 꾸미기`를 연다.
2. 드래곤·그리핀·하늘가오리를 각각 선택하고 해뜰녘·폭풍·달빛 색을 바꿔 본다.
3. 고글과 리본을 붙인 뒤 `돌아가기`로 취소했을 때 원래 캐릭터가 복구되는지 본다.
4. 원하는 조합을 `적용`하고 새로고침 뒤 그대로 남는지 확인한다.
5. 레이스를 시작해 날갯짓, 선회, Space 돌풍, 착륙과 관문 통과를 해 본다.
6. `Esc`에서 공방을 열어 다른 초안을 보고 취소한 뒤 타이머와 미션 진행이 그대로인지 확인한다.
7. 동전 코스와 미션을 하나 끝내 기존 최고 기록·등급·Top 10이 유지되는지 확인한다.

## 기기별 체크

- PC: 마우스, 키보드 Tab/Shift+Tab/Escape, 1280x720 이하 창 크기
- Android: 320px급 세로와 짧은 가로, safe area, 발열과 프레임 저하
- iPhone/iPad Safari: 세로/가로 전환, select 조작, bottom sheet와 화면 확대 여부
- 공통: 캐릭터 전신이 공방에 가리지 않는지, 버튼이 손가락으로 누르기 쉬운지

## 기록할 질문

- 가장 타고 싶은 종족과 이유는 무엇인가?
- 세 팔레트 중 배경·관문과 가장 잘 구분되는 것은 무엇인가?
- 고글/리본 위치가 날갯짓·선회·부스트 중 자연스러운가?
- 다음 추가 항목은 `새 종족`, `눈·뿔·날개 세부 파츠`, `이름 짓기` 중 무엇이 가장 재미있는가?
- 캐릭터를 바꾼 뒤 조작이 달라졌다고 느꼈는가? 느꼈다면 어느 장면인가?

## 실패로 기록할 조건

- 적용하지 않은 초안이 새로고침 뒤 남는다.
- 취소 뒤 원래 외형이 돌아오지 않는다.
- 캐릭터 변경으로 미션, 동전, 기록 또는 고스트 데이터가 사라진다.
- 짧은 세로 화면에서 캐릭터 전신, 적용 또는 돌아가기 동작이 가려진다.
- 종족별로 속도·충돌·부스트 성능이 실제로 달라진다.
- 반복 전환 뒤 캐릭터가 사라지거나 프레임이 계속 낮아진다.

문제는 `기기/브라우저`, `화면 방향`, `선택 조합`, `재현 순서`, `스크린샷 또는 영상`과 함께 기록한다.
