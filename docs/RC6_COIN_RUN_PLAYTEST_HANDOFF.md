# RC6 하늘동전 기록 도전 플레이테스트 인계

> 자동 상태: **RC6 / 하늘동전 기록 도전 자동 검증 완료**
>
> 사람 상태: **실기기·사람 플레이테스트 대기**

## 테스트 목표

세 지역의 10개 동전 동선이 구조물을 통과하는 짧은 기록 도전으로 재미있고, 첫 동전과 다음 동전을 놓치지 않으며, 지역별 최고 기록이 반복 플레이 동기를 만드는지 확인한다.

## 기본 규칙

- 각 지역에 동전 10개가 있고 현재 순서의 동전만 수집된다.
- 1번 동전을 먹는 순간 시간이 0에서 시작하고 10번에서 끝난다.
- 일시정지, 지도, 착륙·이륙 중에는 시간이 흐르지 않는다.
- 지역에서 멀리 벗어나면 현재 시도만 취소되고 최고 기록은 유지된다.
- 완주 후 3초가 지나면 1번 동전이 다시 나타난다.
- 지도에서 각 지역의 로컬 최고 기록을 확인할 수 있다.

## 권장 기기

- 데스크톱 Chromium 키보드, 1440x900 이상
- 실제 Android 또는 iPhone 가로 화면
- 실제 Android 또는 iPhone 세로 화면
- 가능하면 4GB급 저사양 Android 한 대

## 확인 순서

1. `하늘 탐험`으로 들어가 축제 중심섬에서 HUD의 `동전 0/10`과 시간을 확인한다.
2. 첫 동전을 발견하고 10개를 순서대로 모으며 축제 구조물과 동전이 서로 가리지 않는지 본다.
3. 완주 직전 지도를 열고 3초 기다려 시간이 멈추는지 확인한 뒤 닫고 완주한다.
4. 지도에서 축제 중심섬 최고 기록을 확인하고 같은 코스를 더 빠르게 재도전한다.
5. 느린 두 번째 기록이 최고 기록을 덮지 않는지 확인한다.
6. 바람 협곡에서 터널·다리 주변 10개, 구름 유적지에서 계단·기둥 주변 10개를 각각 완주한다.
7. 코스 도중 지역 밖으로 멀리 이동해 시도만 취소되고 기존 기록이 남는지 확인한다.
8. 착륙·재이륙, 지도, 목적지 선택, 기존 레이스 도전, 미션 6종을 한 번씩 사용한다.
9. 모바일 가로·세로에서 동전 HUD와 지도·착륙·조작 버튼이 겹치지 않는지 확인한다.
10. 모바일에서 10분 이상 세 지역을 반복해 발열, 프레임 저하, 엄지 피로를 기록한다.

## 기록할 질문

- 착륙 지점이나 지역 진입 직후 첫 동전을 자연스럽게 발견하는가?
- 다음 동전이 구조물·하늘 색과 충분히 구분되는가?
- 10개 동선이 너무 짧거나 길지 않고 한 번 더 도전하고 싶은가?
- 축제, 협곡, 유적 코스가 같은 패턴처럼 느껴지지 않는가?
- 동전 사이 회전·상승 폭이 키보드와 터치 모두 공정한가?
- 기록이 어디에 저장됐는지 지도에서 바로 이해하는가?
- 3초 재도전 대기가 너무 짧거나 길지 않은가?
- 동전 수집음과 금빛 표현이 수집 성공을 충분히 알려 주는가?
- 구조물 가까이에서 카메라 클리핑, 멀미, 조작 불능이 생기는가?

## 문제 기록 형식

- 기기/OS/브라우저
- 화면 방향과 품질 설정
- 지역 이름과 동전 번호
- 키보드 또는 터치
- 표시된 시간과 기존 최고 기록
- 재현 순서
- 가능하면 10초 영상 또는 스크린샷

## 자동화로 대체할 수 없는 위험

- 실제 모바일 GPU 발열과 장시간 throttling
- 사람마다 다른 첫 동전 발견성과 길 찾기
- 동선 난이도, 기록 경쟁의 재미, 재도전 욕구
- 금화 문양·색·수집음의 만족감
- 구조물 근접 비행의 멀미와 카메라 클리핑

| 동작 | 키보드 | 터치 |
| --- | --- | --- |
| 선회·상승/하강 | 방향키 또는 WASD | 왼쪽 조이스틱 |
| 돌풍 부스트 | Space | 오른쪽 돌풍 버튼 |
| 감속/호버 | C 또는 Ctrl 유지 | 오른쪽 감속 버튼 유지 |

| 일시정지 | Esc | 일시정지 버튼 |
