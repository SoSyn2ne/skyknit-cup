## 인간 게이트

RC1 이후 첫 릴리스 판단에는 처음 보는 플레이어 3명이 필요하다.

- 3명 모두 추가 설명 없이 30초 안에 상승/하강, 선회, 부스트를 수행한다.
- 3명 중 2명 이상이 도움 없이 첫 레이스를 완주한다.
- keyboard 최소 1명, touch 최소 1명을 포함한다.
- touch는 가능하면 실제 Android Chrome 또는 iOS Safari와 실제 safe-area 장치를 포함한다.

이 기준을 통과하기 전에는 `최종 출시 완료`로 변경하지 않는다.

## 준비

1. 저장소 루트에서 `npm install`을 실행한다.
2. `npm run dev -- --host 0.0.0.0`으로 실행한다.
3. 같은 네트워크의 휴대폰에서는 표시된 LAN 주소를 연다.
4. 각 플레이어 전에 브라우저의 `skyknit-cup:settings`와 기존 최고 기록을 지우거나 새 private session을 사용한다.
5. 관찰자는 조작을 설명하지 않고 준비 화면만 보여 준다.
6. 화면/음성을 기록한다면 먼저 플레이어 동의를 받는다.

## 오디오와 복구 관찰

가능하면 한 명에게 다음만 추가 확인한다.

- 첫 입력 전에 브라우저 자동 재생 경고나 소리가 발생하지 않는다.
- 관문, 부스트, 완주 소리를 서로 구분할 수 있다.
- 음소거를 켜고 새로고침해도 유지된다.
- 음량이 놀라울 정도로 크거나 피곤하지 않다.
- 네트워크를 느리게 했을 때 기본 드래곤 안내가 이해된다.

결과:

```text
미기록
```

## 이슈 기록 양식

```text
제목:
플레이어:
장치 / OS / 브라우저:
화면 크기 / 방향:
품질 설정:
reduced-motion:
레이스 phase / 관문 번호:
재현 순서:
예상:
실제:
스크린샷 또는 영상:
심각도: blocker / major / minor / note
```

blocker 예시:

- 시작, 비행, 완주, 재시도 중 하나를 수행할 수 없음
- 다음 관문을 찾을 수 없는 상태가 반복됨
- 터치 대상이 잘리거나 눌리지 않음
- 화면이 검게 남고 복구할 수 없음
- 강한 멀미/불편이 여러 플레이어에게 반복됨
