# Milestone 44 첫 하늘매듭 6관문 스피드 패스 QA

검증일: 2026-08-30

상태: 6관문·활성 미션 간소화 구현 및 실브라우저 검증 완료 / 전역 1초 성능 변동 기록 / 사람·실기기 미실시

## 플레이어 결과

- 첫 하늘매듭은 기존 `gate-01..06`에서 끝난다.
- 실제 비행 물리와 순항 속도는 유지하고 코스 거리만 약 `1,969.5 → 1,466.3 units`로 줄였다.
- 자동 실제 입력 완주는 5개 화면에서 `61.68~62.95초`였다.
- HUD와 미션 진행은 `관문 n/6`, `1:40`, `1:30`, 단축된 돌풍 횟수를 일관되게 표시한다.

## 범위와 보존

- 변경: 첫 하늘매듭 관문 수, 같은 코스를 쓰는 5개 활성 미션의 시간·돌풍 기준, 관련 HUD·테스트.
- 활성 진행: `첫 하늘매듭 → 끊기지 않는 매듭 → 질풍 시간전 → 구름 한 점 없이 → 황금 하늘매듭 → 태양의 심장`. `돌풍 조율사`는 선택 목록에서 제외했다.
- 보존: 비행·부스트·충돌·리스폰·카메라 물리, 태양의 심장 4단계와 75/60/45초, 탐험·동전·오디오, M41 모션, M42 그래픽, M43 안내·가림 개선.
- 저장: v11 형식을 유지하고 기존 최고 등급·Top 10·고스트를 삭제하거나 합성하지 않았다. 이전 8관문 최종 시간은 느린 레거시 값으로 남아 새 기록에 자연스럽게 교체되며, 레거시 `boost-mastery` 등급·미션 Top 10·고스트도 그대로 왕복한다.
- 제외: 새 에셋·의존성·백엔드·포스트프로세싱·코스 추가, 커밋·푸시·배포.

## 성능 판정

M44 첫 하늘매듭 재측정은 다음과 같다.

| 프로필 | 중앙값 FPS | 최저 1초 FPS | draw calls | triangles |
| --- | ---: | ---: | ---: | ---: |
| desktop/high | 60 | 60 | 63 | 69,408 |
| mobile/low | 60 | 60 | 38 | 37,724 |

전역 성능 테스트는 완전 통과로 기록하지 않는다.

- 전체 첫 실행: 첫 하늘매듭 desktop 최저 1초가 49fps였고 나머지 일반·탐험·화산·수호수 프로필은 예산을 만족했다.
- 단독 재측정: 첫 하늘매듭은 60/60fps로 회복했으나 변경하지 않은 화산 미션의 최저 1초가 46fps였다. 해당 2초 최저는 52.5fps였다.
- 실패 지점이 이동했고 첫 하늘매듭 저하는 재현되지 않아 M44 렌더 비용 회귀로 판정하지 않았다. 다만 전역 1초 하한의 호스트 스케줄링성 변동은 후속 성능 안정성 작업에 남긴다.
