# RC3 캐릭터 플레이테스트 인계

> 자동 상태: **RC3 / 캐릭터 리마스터 자동 검증 완료**
>
> 사람 상태: **실기기·사람 플레이테스트 대기**

## 테스트 목표

Dragon v3가 단순히 더 복잡한 모델이 아니라 더 생생하고 읽기 쉬운 공중 경주 캐릭터로 느껴지는지 확인한다.

## 권장 기기

- 데스크톱 Chromium 키보드
- 실제 Android 또는 iPhone 가로 화면
- 실제 Android 또는 iPhone 세로 화면

## 확인 순서

1. 준비 화면에서 주홍 몸, 금빛 날개막, 뿔, 날개 손가락과 꼬리 지느러미가 읽히는지 본다.
2. 비행을 시작해 카메라 전환이 튀거나 멀어지지 않는지 확인한다.
3. 상승/하강과 좌우 선회에서 어깨, 몸통, 꼬리의 지연이 생물처럼 느껴지는지 본다.
4. 부스트에서 눈이 좁아지고 턱과 날개 자세가 속도감을 주는지 본다.
5. 장애물 충돌에서 짧은 찡그림과 색 피드백이 과하지 않은지 본다.
6. 첫 하늘매듭 미션을 완주하고 재시도해 기존 미션/저장이 정상인지 확인한다.
7. 세로/가로 터치에서 드래곤이 관문이나 조작 버튼을 가리지 않는지 확인한다.

## 기록할 질문

- 드래곤 얼굴과 실루엣이 기억에 남는가?
- 날개와 꼬리 움직임이 조작 방향을 이해하는 데 도움 되는가?
- 카메라가 너무 가깝거나 멀거나 멀미를 유발하는가?
- 모바일에서 다음 관문을 놓치는 순간이 있는가?
- 부스트와 충돌 표정이 보이는가, 아니면 너무 짧거나 과한가?

## 자동 검증으로 대체할 수 없는 위험

- 실제 GPU 열 throttling과 고DPR 성능
- notch/safe-area의 제조사별 차이
- 캐릭터의 매력과 표정 전달력
- 2~4분 플레이 후 멀미와 손가락 피로

문제가 발견되면 기기, 방향, 품질 설정, 미션, 체크포인트 번호와 가능하면 10초 영상을 함께 남긴다.
