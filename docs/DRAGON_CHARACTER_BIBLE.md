# 하늘매듭배 비행 생명체 캐릭터 바이블

> 상태: **RC11 기본 드래곤 보존 / 다종 캐릭터 확장 기준**

## 기본 드래곤 정체성

해뜰녘 하늘 축제를 질주하는 주홍빛 공중 경주 드래곤으로, 전투용 괴수보다 날렵한 운동선수처럼 보이고 눈과 자세로 집중력과 생동감을 전달한다.

## 시각 서명

- 주홍 몸과 짙은 버건디 그림자 면
- 금빛 가슴 배판과 넓은 날개막
- 청록 눈과 어깨의 바람 룬
- 숯빛 후방 뿔, 볼 가시, 날개 끝과 발톱
- 다이아몬드형 금빛 인레이가 있는 꼬리 지느러미

갑옷, 안장, 무기, 기계 부품과 배기 효과는 사용하지 않는다. RC11의 바람 고글과 축제 리본은 전투 장비가 아닌 가벼운 축제 장식이며 실루엣과 얼굴을 가리지 않는다.

## RC11 캐릭터 패밀리

- **해뜰녘 드래곤:** 기존 주홍 운동선수 실루엣과 표정을 기준점으로 보존한다.
- **폭풍 그리핀:** 깃털 부채 날개, 짧은 부리와 고양잇과 몸통으로 읽히며 드래곤의 뿔·긴 목·막날개를 복제하지 않는다.
- **구름 하늘가오리:** 납작한 다이아몬드 몸통, 넓은 유영 지느러미와 채찍 꼬리로 읽히며 다리나 드래곤형 주둥이를 만들지 않는다.

세 형태는 동일한 `DragonRoot`, 양쪽 날개/지느러미, 머리와 다섯 꼬리 피벗을 사용한다. 이 이름은 레거시 런타임 호환을 위한 기술 계약일 뿐 모든 캐릭터가 용이라는 의미가 아니다.

팔레트는 몸·날개막·발광의 세 재질 역할만 바꾼다. 해뜰녘은 주홍/금/청록, 폭풍은 남청/은/전기 청록, 달빛은 자주/진주/연보라를 사용한다. 배경과 관문 색은 팔레트 선택의 영향을 받지 않는다.

장식은 `없음`, 머리 소켓의 `바람 고글`, 꼬리 소켓의 `축제 리본`으로 제한한다. 종족별 오프셋은 카탈로그에 명시하고 날갯짓·선회·부스트에서 몸을 뚫거나 떠 있으면 실패다.

## 비율과 실루엣

- 가슴은 넓고 허리는 가볍게 좁아지며 골반이 꼬리로 자연스럽게 이어진다.
- 목은 가슴에서 S자 곡선으로 올라가고 머리는 몸통보다 작아 경주용 체형을 유지한다.
- 날개폭은 몸통과 꼬리 길이를 압도하되 접었을 때 관문을 가리지 않는다.
- 어깨와 날개 뿌리는 하나의 근육 덩어리로 읽히고 날개 손가락은 부채처럼 간격이 벌어진다.
- 앞다리는 가볍고 뒤다리는 추진 근육이 더 크다. 비행 중 발은 몸 아래로 정돈된다.
- 꼬리는 다섯 구간에 걸쳐 일정하게 가늘어지고 끝의 다이아몬드 지느러미가 선회 방향을 강조한다.

## 얼굴과 표정

- 쐐기형 주둥이, 낮은 눈썹뼈, 분리된 볼과 턱선으로 정면과 3/4에서 얼굴을 읽힌다.
- 청록 눈은 어두운 세로 동공과 작은 밝은 하이라이트를 가진다.
- 콧구멍과 입선은 큰 면을 깨지 않는 짧은 숯빛 악센트로 표현한다.
- 평상시에는 입을 닫고 눈을 편안하게 연다.
- 부스트에서는 머리를 낮추고 눈을 좁히며 턱이 아주 조금 열린다.
- 충돌에서는 짧게 눈을 찡그리고 턱과 머리가 움찔한 뒤 원래 자세로 복귀한다.
- 눈 깜빡임은 규칙적 기계 반복이 아니라 결정적 주기 안의 짧은 비대칭 타이밍을 사용한다.

## 형태별 구현 우선순위

1. 머리 외곽, 눈, 뿔 방향
2. 날개 외곽과 손가락 사이의 막 분할
3. 어깨, 가슴, 목의 연결
4. 발목, 발가락, 발톱의 방향
5. 꼬리 굵기와 지느러미
6. 가까이서만 보이는 콧구멍, 입선, 눈 하이라이트

전신에 작은 비늘을 반복하지 않는다. 로우폴리 면 분할은 근육 흐름과 색 덩어리를 설명할 때만 사용한다.

## 카메라별 가독성

### 준비 화면

- 얼굴, 눈, 뿔, 가슴 배판과 양쪽 날개 뿌리가 보이는 3/4 영웅 구도
- 시작 조작과 미션 선택을 가리지 않고 5초 안에 출발 가능

### 레이스 화면

- 어깨와 날개 외곽, 주홍 몸통, 꼬리 지느러미가 한눈에 읽힌다.
- 드래곤의 화면 점유율을 높이기 위해 다음 관문이나 두 가닥 바람실을 가리지 않는다.
- `320x568`에서는 눈의 미세 디테일보다 주홍/금빛 색 분리와 날개·꼬리 외곽을 우선한다.

## 런타임 계약

- 필수: `DragonRoot`, `WingRig_L/R`, `HeadRig`, `TailRig_1..5`
- 선택: `JawRig`, `EyeRig_L/R`
- 선택 피벗이 없으면 턱과 눈 표현만 생략하고 비행 애니메이션은 계속 동작한다.
- 충돌 피드백은 원래 청록 발광을 보존하고 종료 후 원재질 상태로 정확히 복구한다.

## 검수 질문

- 검은 실루엣만 봐도 머리, 날개, 다리, 꼬리가 구분되는가?
- 준비 화면에서 눈과 표정이 읽히는가?
- 레이스 화면에서 날개와 꼬리 움직임이 관문보다 먼저 시선을 빼앗지 않는가?
- 폴리곤 증가가 실제 외곽과 해부학 개선에 쓰였는가?
- 전투 드래곤, 자동차 스킨, 귀여운 마스코트로 오해될 요소가 없는가?
