# Milestone 32 오픈월드 플레이테스트 인계

> 자동 상태: **전체 자동 검증 완료**
>
> 사람 상태: **실기기·10~15분 플레이테스트 대기**

## 테스트 목표

축제 중심섬의 다섯 랜드마크, 세 상승기류, 비밀 장소, 세 착륙장, 하늘동전 기록과 선택 레이스 미션이 설명서 없이도 하나의 10~15분 여정으로 이어지는지 확인한다. 자동화가 증명한 좌표와 상태 전이만 반복하지 말고, 실제 조작에서 장소 찾기, 동선 가독성, 충돌 감각, 오디오 균형, 모바일 발열과 터치 피로를 판단한다.

## 실행 준비

- Node.js `22.20.x`
- 브랜치 `codex/m32-open-world-vertical-slice`
- 실제 모바일과 같은 Wi-Fi에 연결된 개발 PC
- 테스트 전에 브라우저 콘솔과 네트워크 로그를 보존할 수 있는 환경

```powershell
node --version
npm ci
npm run build
npm run preview -- --host 0.0.0.0 --port 4173
```

데스크톱은 `http://127.0.0.1:4173/`, 실제 모바일은 preview 터미널에 표시된 PC의 LAN 주소로 접속한다. 위 명령은 현재 `package.json`, `package-lock.json`과 Vite preview 스크립트에 맞춘 것이다.

첫 세션은 새 브라우저 프로필이나 사이트 저장소를 지운 상태로 시작한다. 두 번째 세션에서는 저장소를 지우지 말고 reload와 복구를 확인한다.

| 동작 | 키보드 | 터치 |
| --- | --- | --- |

| 좌우 선회 | `A/D` 또는 `←/→` | 왼쪽 가상 조이스틱 가로축 |
| 돌풍 부스트 | `Shift` 또는 `Space` | `돌풍` 버튼 |
| 감속/호버 | `C` 또는 `Ctrl` 유지 | `감속` 버튼 유지 |
| 착륙·이륙·레이스 도전 | `E` 또는 `Enter` | 화면의 상황 동작 버튼 |
| 지도 열기/닫기 | `M` | `지도` 버튼 |

탐험은 감속해 호버할 수 있지만 후진은 지원하지 않는다. 착륙, 이륙과 레이스 도전은 유효 위치에서만 상황 동작으로 나타난다.

## 첫 10~15분 필수 동선

자동 QA 이동 함수를 사용하지 말고 실제 조작으로 진행한다. 준비 화면에서 먼저 `첫 하늘매듭`을 선택하면 최종 레이스의 기본 성공 조건을 판정하기 쉽다. 고급 반복 테스트에서는 `황금 하늘매듭`으로 바꾼다.

### 0~1분: 출발

1. 준비 화면을 연다. 사용자 동작 전 BGM과 환경음이 재생되지 않는지 확인한다.
2. 미션을 선택하고 `하늘 탐험`을 누른다.
3. BGM이 한 번만 시작하고 HUD에 `여정 0/5`와 다음 목표가 보이는지 확인한다.

### 1~4분: 공개 랜드마크와 상승기류

1. 새벽날개 비행장에서 방향과 호버를 익힌다.
2. 바람 직조기, 왕관 레이스 아치, 햇실 첨탑을 순회한다.
3. `항구 상승류`, `아치 순풍`, `첨탑 나선류`를 각각 한 번 통과한다.
4. 힘을 받았을 때 위치와 상승·전진 감각이 분명하고, 첫 진입에만 짧은 큐가 들리는지 확인한다.
5. HUD가 공개 랜드마크 `4/4`, 상승기류 `3/3`까지 진행하는지 확인한다.

### 4~6분: 비밀 장소와 착륙

1. 지도와 지형 실루엣만 사용해 속삭임 동굴을 찾는다.
2. `비밀 장소 발견 · 속삭임 동굴` 알림이 한 번 표시되는지 확인한다.
3. 중심 비행장, 햇실 첨탑 전망대, 동굴 선반 세 곳에서 각각 착륙하고 즉시 재이륙한다.
4. 착륙 유효 범위 밖에서는 버튼이 나타나지 않고, 유효 범위에서는 `착륙` → `이륙`으로 바뀌는지 확인한다.

### 6~10분: 하늘동전 기록

1. 축제 중심섬의 현재 금빛 동전을 찾아 1번부터 10번까지 순서대로 수집한다.
2. 첫 동전 전에는 시간이 0이고 첫 동전부터 타이머가 진행되는지 확인한다.
3. 구조물 근접 구간에서 동전, 드래곤과 다음 비행선이 서로 가려지지 않는지 본다.
4. 마지막 동전 뒤 지역 최고 기록이 표시되고 지도에 `동전 최고`가 갱신되는지 확인한다.

### 10~15분: 선택 미션

1. 왕관 레이스 아치로 돌아가 `레이스 도전` 상황 동작을 실행한다.
2. 준비 화면에서 골랐던 미션이 그대로 활성화되는지 확인한다.
3. 12개 관문을 순서대로 완주한다. 첫 플레이 목표는 2~4분이다.
4. 탐험으로 돌아오면 축제 여정이 `5/5 · 축제 여정 완료`인지 확인한다.
5. 실제 시작부터 완료까지 걸린 시간을 기록한다. 10분보다 짧거나 15분보다 길면 어디에서 시간이 달라졌는지 적는다.

## 지도와 길찾기 판정

- 지도는 랜드마크 `n/4`, 상승기류 `n/3`, 비밀 발견 여부, 동전 최고 기록과 선택 미션의 왕관 레이스 아치 안내를 읽을 수 있게 보여야 한다.
- 지도를 연 동안 비행, 바람·충돌·발견 진행과 착륙·이륙 입력이 멈추고 BGM만 이어져야 한다.
- 비행 HUD는 한 번에 다음 목표 하나만 강조해야 한다.
- 지도 없이도 다섯 랜드마크를 실루엣·높이·색·재질 중 두 가지 이상의 차이로 구분할 수 있어야 한다.
- 금빛 현재 동전, 금빛 레이스 관문과 두 가닥 바람실이 랜드마크·바람 리본·안개에 묻히면 실패로 기록한다.
- 320x568에서도 여정, 지역명, 동전 기록, BGM, 지도, 일시정지와 상황 버튼이 터치 조작을 막지 않아야 한다.

## 충돌과 착륙 판정

1. 햇실 첨탑 기둥과 Wind Loom 바깥 기둥을 중간 속도로 스치고, 이어서 부스트 상태로 접근한다.
2. 구조물을 관통하지 않고 속도만 감소하며 즉사·검은 화면·레이스 기록 변경이 없는지 확인한다.
3. Wind Loom의 두 기둥 사이 중앙은 드래곤이 통과할 수 있어야 한다.
4. 세 착륙장 접근 중 보이지 않는 충돌벽, 카메라 클리핑과 착륙 버튼 깜빡임이 없어야 한다.
5. 10개 동전 동선에서 구조물이 수집 반경을 막거나 강제로 충돌시키는 구간이 없어야 한다.

## 오디오 필수 순서

1. 첫 동작 전: BGM, 바람층과 효과음이 모두 조용해야 한다.
2. `하늘 탐험` 시작: `Sovereign of the Sunrise Skies`가 한 번 시작하고 낮은 바람층이 함께 들려야 한다.
3. 일반 하늘과 상승기류 중심을 왕복: 바람층 강도가 부드럽게 변하고 새 AudioContext나 끊김이 들리지 않아야 한다.
4. 새 랜드마크·새 상승기류: 각각 첫 발견에서만 짧은 큐가 들려야 한다.
5. 날갯짓과 돌풍: 날개 하강 박자의 에어 펄스와 0.78초 `슈우웅`이 BGM을 덮지 않아야 한다.
6. 레이스 전환: BGM 위치는 이어지고 탐험 바람층만 사라져야 한다.
7. mute와 BGM 0%·35%·100%: mute는 BGM과 SFX 모두, BGM 슬라이더는 음악만 조절해야 한다.
8. 탭 숨김·복귀: 숨김 중 모든 오디오가 멈추고 복귀 뒤 중복 재생 없이 이어져야 한다.
9. 헤드폰과 기기 스피커에서 각각 최소 한 번 전체 흐름을 듣고 음량 불균형과 피로를 기록한다.

## 저장·복구 순서

1. 랜드마크 일부와 상승기류 일부만 발견한 상태에서 새로고침한다.
2. 준비 화면에서 사용자 동작 전 자동재생이 없고, 탐험 재진입 뒤 발견 수가 유지되는지 확인한다.
3. 세 착륙장마다 착륙 상태에서 새로고침하고 같은 패드 위치에서 재이륙하는지 확인한다.
4. 비밀 장소, 동전 10개와 레이스를 완료한 뒤 다시 새로고침한다.
5. 여정 `5/5`, 동전 최고 기록, 레이스 최고 기록, 선택 미션 등급, 음소거·BGM 볼륨과 품질 설정이 유지되는지 확인한다.
6. 가능하면 개발자 도구로 WebGL context loss/recovery를 한 번 유도한다. 복구 뒤 탐험 위치와 기록이 남고 BGM·환경음이 중복되지 않아야 한다.

## 장시간·모바일 판정

- 실제 모바일에서 10~15분 여정을 두 번 반복한다.
- 두 번째 반복에는 지도 열기/닫기, 세 착륙장, 동전 기록 재도전과 다른 레이스 미션을 포함한다.
- 5분, 10분, 종료 시점의 체감 발열, 프레임 저하, 배터리 변화와 엄지 피로를 기록한다.
- 방향 전환, 앱 전환과 브라우저 UI 축소·확장 뒤 safe area와 터치 좌표가 어긋나지 않아야 한다.
- 장시간 반복에서 랜드마크가 사라지거나 두 LOD가 겹치고, 오디오가 중첩되거나 점점 커지고, 새 stutter가 누적되면 실패다.

## 사람 통과 기준

- 처음 보는 플레이어가 별도 설명 없이 공개 랜드마크 4곳, 상승기류 3곳과 비밀 동굴을 찾는다.
- 첫 5단계 축제 여정을 실제 조작으로 10~15분 안에 완료한다.
- 세 착륙장 모두 착륙·재이륙이 자연스럽고 구조물 충돌이 예측 가능하다.
- 10개 동전과 12개 레이스 관문의 다음 목표가 항상 읽힌다.
- BGM은 모드 전환에서 끊기지 않고, 탐험 환경음과 발견 큐는 음악을 덮지 않는다.
- reload, 탭 숨김·복귀와 context recovery에서 기록·설정·오디오가 중복되거나 손실되지 않는다.
- 실제 Android와 iPhone에서 조작을 방해하는 발열, throttling, 터치 피로와 UI 겹침이 없다.
- 전경 동전 가림, 원거리 섬 명암, 밝은 하늘의 옅은 바람 리본이 실제 비행 판단을 방해하지 않는다.
